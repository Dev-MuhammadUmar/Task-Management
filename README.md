# Task Management App

A full-stack MERN project for managing tasks with CRUD functionality.

## Project structure

- `client/` - React + Vite frontend
- `server/` - Express.js + Mongoose backend API

## Local setup

1. Copy `server/.env.example` to `server/.env` and update the MongoDB connection string.
2. Start MongoDB locally.
3. Run the backend in `server/` with `npm run dev`.
4. Run the frontend in `client/` with `npm run dev`.
